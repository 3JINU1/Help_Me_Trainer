# Help_Me_Trainer

운동 루틴을 만들고, 계획을 짜고, 기록을 추적할 수 있는 iOS 중심의 헬스 트레이닝 앱입니다.

## 0.1.0 기본 기능

- 운동 루틴 생성/수정/삭제
- 요일별 루틴 지정
- 운동 세트 진행 상태 기록
- 휴식 타이머 및 유산소 타이머
- 오늘의 운동 계획 관리
- 캘린더 기반 운동 일정 확인
- 운동별 진행 그래프와 추세 보기
- 로컬 저장소 기반 기록 유지

## 0.2.1 업데이트

### 새 기능

- 운동 선택 검색 및 영어 필터 UI
- 덤벨, 바벨, 케이블, 머신, 자세, 그립, 동작 패턴 필터 준비
- 캘린더 루틴 카드 접기/펼치기
- 완료한 루틴 상태 확인 및 완료 초기화

### 오류 수정

- 새 루틴 생성 시 이전 루틴 운동 목록이 복사되던 문제 수정
- 검색어 입력 후 운동 목록이 갱신되지 않던 문제 수정
- 운동 선택 창의 키보드 overflow 표시 수정
- 운동 선택 목록의 불필요한 구분선 제거
- 미배정 요일에 다른 루틴이 자동 표시되던 문제 수정
- 완료 루틴 초기화 시 캘린더 체크와 운동 기록을 함께 삭제
- 휴식 타이머 표시 중 화면 overflow 수정
- 초기화 확인창의 색상과 텍스트 가독성 개선

## IPA 파일 만들기 및 설치

### 1. iOS 릴리스 아카이브 생성

```bash
cd hmtrainer
flutter build ipa --no-codesign
```

코드 서명을 하지 않은 경우 `.ipa` 대신 다음 아카이브가 생성됩니다.

```text
hmtrainer/build/ios/archive/Runner.xcarchive
```

### 2. IPA 패키지 만들기

```bash
rm -rf /tmp/hmt-ipa
mkdir -p /tmp/hmt-ipa/Payload
cp -R build/ios/archive/Runner.xcarchive/Products/Applications/Runner.app \
	/tmp/hmt-ipa/Payload/
cd /tmp/hmt-ipa
zip -qr ~/Desktop/HMT.ipa Payload
```

완성된 파일은 바탕화면의 `HMT.ipa`입니다.

### 3. 아이폰에 설치

1. `HMT.ipa`를 AirDrop으로 아이폰에 전송합니다.
2. 파일 앱에서 IPA 파일을 선택하고 공유합니다.
3. 공유 대상에서 AltStore를 선택합니다.
4. AltStore에서 Apple ID로 서명 후 설치합니다.

코드 서명 없이 생성한 IPA는 AltStore 또는 Apple 개발자 인증서로 서명해야 설치할 수 있습니다. 무료 Apple ID 사용 시 서명이 만료되기 전에 AltStore에서 앱을 Refresh해야 합니다.

## 현재 구조

- 루틴 관리: 운동 이름, 세트, 반복, 무게, 유산소 시간 설정
- 운동 진행: 세트별 완료 체크와 휴식 타이머 활용
- 기록: 완료한 운동을 저장하고 그래프로 확인
- 일정 관리: 캘린더/요일에 루틴 연결
