# Help_Me_Trainer

운동 루틴을 만들고, 계획을 짜고, 기록을 추적할 수 있는 iOS 중심의 헬스 트레이닝 앱입니다.

## 0.1.0 출시 내용

- 운동 루틴 생성/수정/삭제
- 요일별 루틴 지정
- 특정 날짜 루틴 지정
- 운동 세트 진행 상태 기록
- 휴식 타이머 및 유산소 타이머
- 오늘의 운동 계획 관리
- 캘린더 기반 운동 일정 확인
- 운동별 진행 그래프와 추세 보기
- 로컬 저장소 기반 기록 유지

## 실행 방법

```bash
cd hmtrainer
flutter pub get
flutter run
```

## 현재 구조

- 루틴 관리: 운동 이름, 세트, 반복, 무게, 유산소 시간 설정
- 운동 진행: 세트별 완료 체크와 휴식 타이머 활용
- 기록: 완료한 운동을 저장하고 그래프로 확인
- 일정 관리: 캘린더/요일에 루틴 연결

## 버전 정보

- 현재 버전: 0.1.0
