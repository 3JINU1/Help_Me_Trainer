# hmtrainer

Help_Me_Trainer의 Flutter 앱입니다.

## 0.1.0

이 버전은 기본 기능 중심의 운동 트레이너 MVP입니다.

### 포함 기능

- 운동 루틴 생성, 로드, 삭제
- 오늘/요일/날짜별 루틴 연결
- 세트별 운동 진행 기록
- 휴식 시간 및 유산소 시간 타이머
- 오늘 운동 완료 처리
- 캘린더 기반 운동 일정 확인
- 운동별 추세 및 그래프 시각화
- SharedPreferences 기반 로컬 저장

### 실행

```bash
flutter pub get
flutter run
```
