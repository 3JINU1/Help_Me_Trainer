# hmtrainer

Help_Me_Trainer의 Flutter 앱입니다.

## 0.2.1

기본 운동 기능에 루틴 캘린더 관리와 운동 선택 UX 개선을 반영한 MVP 업데이트입니다.

### 포함 기능

- 운동 루틴 생성, 로드, 삭제
- 요일별 루틴 연결
- 세트별 운동 진행 기록
- 휴식 시간 및 유산소 시간 타이머
- 오늘 운동 완료 처리
- 캘린더 기반 운동 일정 확인
- 운동별 추세 및 그래프 시각화
- 운동 선택 검색 및 영어 필터 UI
- 캘린더 루틴 카드 펼치기/접기
- 완료 루틴 체크 표시와 완료 초기화
- SharedPreferences 기반 로컬 저장

### 오류 수정

- 새 루틴 생성 시 기존 운동 목록이 남던 문제 수정
- 검색 입력 후 결과 목록이 갱신되지 않던 문제 수정
- 운동 선택 창과 휴식 창의 화면 overflow 수정
- 미배정 요일에 루틴이 자동 배정되던 문제 수정
- 완료 초기화 시 해당 날짜의 체크와 기록 삭제
- 초기화 확인창을 흰색 배경과 검은색 텍스트로 통일

### 실행

```bash
flutter pub get
flutter run
```
